INSTALL SIDETRAY

Drag SideTray onto Applications, then open it from Applications.

IF MACOS SAYS “SIDETRAY” NOT OPENED

SideTray is downloaded directly from GitHub. If macOS blocks it:

1. Choose Done in the warning.
2. Open System Settings → Privacy & Security and scroll to Security.
3. Find SideTray and choose Open / Open Anyway.
4. Confirm with Touch ID or your password, then open SideTray.

SET UP SIDETRAY

Click Request Access for each permission and enable SideTray in System
Settings. If it is missing from a list, drag the SideTray icon from its
setup window into that list.
Choose Quit & Reopen if macOS asks.

Select the apps you want to keep visible, then click Start SideTray.
